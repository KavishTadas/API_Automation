Design patterns and implementation style
- Data-driven testing:
  - CSV files in test-data/ map to collection filenames.
  - test-data/Leave_API.csv feeds collections/Leave_API.json.
- Ordered test execution:
  - scripts/run-newman.js forces Employee_Auth_API.json before Leave_API.json so auth can run first.
- Shared test context:
  - authToken and other non-empty Newman environment values are carried forward between collection runs.
- Generated reports:
  - Per-collection HTML files are generated with htmlextra.
  - Allure raw results are generated under reports/allure-results.
  - A consolidated HTML index is generated under reports/html/index.html.
  - The consolidated index includes Newman collection results plus auto-generated pytest results when Allure JSON or JUnit XML is present.
- Generated API file:
  - scripts/generate-api-file.js reads collections/ and bruno/.
  - It skips .pending. collections and non-request Bruno environment files.
  - It writes api-docs/API_File.csv and api-docs/API_File.json.
  - It detects authToken producers/consumers and links dependent APIs to the login/token-producing API.
  - It includes example request and response payload fields, masking sensitive placeholders such as passwords and tokens.
  - It preserves existing API row order, refreshes matching rows, appends newly discovered APIs, and records missing APIs in history.
  - It snapshots previous API_File CSV/JSON versions into api-docs/history/ for audit.
- Generated generic tests:
  - scripts/generate-generic-tests.py reads api-docs/API_File.json first, then falls back to CSV.
  - It writes tests/auto_generated/ pytest files, shared helpers, and fixtures.
  - Generated tests use httpx, API File method/endpoint/body/parameters, and optional bearer auth when authToken is required.
  - Rows with missing base URL/endpoint are marked skipped.
  - Negative/non-200 API rows are marked skipped because they do not document a valid 200 request.
- Contract-first reference:
  - openapi/openapi.yaml describes expected endpoint behavior and schemas.
- CI artifact publishing:
  - GitHub Actions uploads HTML, Allure results, and Allure HTML report artifacts.
